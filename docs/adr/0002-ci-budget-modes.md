# ADR 0002: CI budget modes

We needed a way to share one Blacksmith free tier across multiple projects without a runaway repo exhausting the pool for the others. We introduce an org/repo variable `CI_BUDGET_MODE` with three modes — `normal` (run PR Check), `thin` (skip linear-cli PR Check jobs so the higher-priority Win-CodexBar flow gets the pool), and `off` (skip everything) — treating unset/empty as `normal`. The PR Check job is gated by `vars.CI_BUDGET_MODE != 'off' && vars.CI_BUDGET_MODE != 'thin'`; Release jobs are gated by `vars.CI_BUDGET_MODE != 'off'` (a manual dispatch still runs in `thin`, since an operator explicitly asked). This gives operators a single knob to defer or shut off CI spend per repo without editing workflow files, and the intended split is roughly 60/30/10 across normal/thin/off so the pool covers priority work first.
